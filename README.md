Weather MCP Server

A simple MCP (Model Context Protocol) server that gives real-time weather for any city. Built with Python, FastMCP, and Open-Meteo free APIs (No API key needed!).

GitHub: https://github.com/dhamodharan091205-alt/weather-mcp-server
Created by: Dhamodharan.R
Features
- Get current weather for any city (e.g., Chennai, London, Tokyo)
- No API Key Required - Uses Free Open-Meteo APIs
- Works with Claude Desktop
- Async & Fast
Tech Stack
- Python 3.10+
- FastMCP
- httpx
- Open-Meteo Geocoding + Weather API
